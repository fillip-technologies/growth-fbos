=================== ENDPOINTS ===================

==================================================
ENDPOINT: GET /api/management/v1/kpi-targets
TITLE: List KPI targets
PERMISSION: planning.target.read
ID: op-listKpiTargets
Note: 200 OK with a page of KpiTarget items.

==================================================
ENDPOINT: POST /api/management/v1/kpi-targets
TITLE: Create a KPI target (draft)
PERMISSION: planning.target.create
ID: op-createKpiTarget
Note: Changing an approved target creates a new revision that supersedes the old one after approval.
Note: 201 Created with KpiTarget.

==================================================
ENDPOINT: POST /api/management/v1/kpi-targets/{target_id}/submit
TITLE: Submit a target for approval
PERMISSION: planning.target.submit
ID: op-submitKpiTarget
Note: 200 OK with KpiTarget.

==================================================
ENDPOINT: GET /api/management/v1/kpi-definitions
TITLE: List KPI definitions
PERMISSION: performance.kpi.read
ID: op-listKpiDefinitions
Note: 200 OK with a page of KpiDefinition items.

==================================================
ENDPOINT: GET /api/management/v1/kpi-results
TITLE: Get KPI results (target vs actual)
PERMISSION: performance.kpi.read
ID: op-listKpiResults
Note: Results are recalculated within about 30 seconds of the business events that feed them.
Note: 200 OK with a page of KpiResult items.

==================================================
ENDPOINT: POST /api/management/v1/measurements
TITLE: Record a manual measurement
PERMISSION: performance.measurement.create
ID: op-recordMeasurement
Note: Only for KPIs whose source type is manual (for example survey results). Event-fed KPIs reject manual values.
Note: 201 Created with an empty body.

==================================================
ENDPOINT: GET /api/management/v1/corrective-actions
TITLE: List corrective actions
PERMISSION: performance.corrective.read
ID: op-listCorrectiveActions
Note: 200 OK with a page of CorrectiveAction items.

==================================================
ENDPOINT: POST /api/management/v1/corrective-actions
TITLE: Create a corrective action
PERMISSION: performance.corrective.create
ID: op-createCorrectiveAction
Note: 201 Created with CorrectiveAction.

==================================================
ENDPOINT: GET /api/management/v1/availability
TITLE: Find available people
PERMISSION: resource.availability.read
ID: op-findAvailability
Note: Ordered by free minutes, then skill level, then cost rate.
Note: 200 OK with a page of ResourceAvailability items.

==================================================
ENDPOINT: POST /api/management/v1/allocations
TITLE: Allocate a person to work
PERMISSION: resource.allocation.create
ID: op-createAllocation
Note: Over-allocation is refused unless override_reason is given by a user with resource.allocation.override; the overloaded days are listed in the error meta.
Note: 201 Created with Allocation.

==================================================
ENDPOINT: GET /api/management/v1/capacity
TITLE: Get capacity for a unit
PERMISSION: resource.capacity.read
ID: op-getCapacity
Note: 200 OK with CapacitySummary.
